# Changelog

## 0.1.0

First port of the VS Code extension `worktree-diff` 0.19.0 to the IntelliJ Platform.

- DevFlow tool window with the Worktrees tree and the OpenSpec board.
- Diff of any changed file against the merge base, left side read from git.
- OpenSpec detail and Aria info as editor tabs, rendered through JCEF.
- Claude Code sessions opened in a terminal tab started in the worktree, prompt in English or French.
- Start new work, create worktree for a drafted change, agent launch requests with human approval.
- Per-project settings under Tools | Worktree Diff.
